# 🚕 Urban Routes - Selenium Test Automation

## 📌 About the Project

This project contains automated end-to-end tests for the Urban Routes web application, a taxi ordering platform.

The tests cover the full user flow of requesting a taxi using Selenium WebDriver, Pytest, and the Page Object Model pattern.

---

## 🎯 Test Objective

The objective of this project is to automate the main taxi ordering flow, validating that users can successfully complete the process from route selection to car search.

---

## 🧪 Test Scenarios Covered

The automated tests cover the following actions:

* Set pickup and destination addresses
* Select the Comfort plan
* Fill in the phone number
* Retrieve and enter the SMS confirmation code
* Add a credit card
* Add a comment for the driver
* Request blanket and handkerchiefs
* Add 2 ice creams
* Order a taxi
* Verify that the car search modal appears

## ▶️ How to Run the Tests

1. Clone this repository:

```bash
git clone https://github.com/dheborabeltrao-qa/QA-Brazil_Python_Automation.git
```

2. Install the dependencies:

```bash
pip install -r requirements.txt
```

3. Run the tests:

```bash
pytest main.py
```
